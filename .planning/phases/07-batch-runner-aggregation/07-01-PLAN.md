scipy.stats.t.interval signature (RESEARCH §D.6 — CITED from scipy docs):
`scipy.stats.t.interval(confidence, df, loc=0, scale=1)` returns `(lower, upper)` 2-tuple of floats.

For Phase 7: `confidence=0.95`, `df=n-1`, `loc=mean`, `scale=sem=std/np.sqrt(n)`.

N=1 edge case (RESEARCH §D.8 — VERIFIED runtime: `np.std([42.0], ddof=1)` returns `nan` with `RuntimeWarning`). Guard MUST be `if n == 1:` BEFORE calling `values.std(ddof=1)`.

Float precision (PATTERNS.md §7 Pitfall 3) — all test float assertions MUST use `assertAlmostEqual(places=4)` to tolerate BLAS variations across numpy versions.

Hand-computed CI for TestCIComputation (one canonical worked example):

- mean = 92.05, std (ddof=1) ≈ 0.302765..., sem = 0.302765/sqrt(10) ≈ 0.09575
- df=9, scipy.stats.t.ppf(0.975, df=9) ≈ 2.262157...
- ci_lower ≈ 92.05 - 2.262157 × 0.09575 ≈ 91.834..., ci_upper ≈ 92.265...

Use `assertAlmostEqual(places=2)` for the CI ends (allow numerical breathing room across scipy versions).
