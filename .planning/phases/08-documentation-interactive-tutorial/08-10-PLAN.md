<objective>
Close UAT Gap 5 — replace the no-mode hard error (`Musisz podać jeden z
trybów: ...` via p.error → exit 2) with a graceful default + informational
banner. When user runs `python sph_sim.py` with no flag, auto-promote to
--interactive AND print a Polish banner to stderr explaining the implicit
choice and listing the 4 alternate modes (--strategy, --custom, --batch,
--tutorial) with one-line descriptions.

Purpose: User requested discoverability over penalty. The current contract
(exit 2 on bare invocation) is hostile for new users who don't yet know which
flag they want. The new contract teaches the user the available modes while
still doing the most likely thing (boot the REPL).

Output: 4 modified files — args.py (the contract change), test_tutorial.py
(flipped test), verify_phase8.sh (C7 grep flip), verify_phase3.sh (Phase 3
retro grep flip). regression_check.py is UNCHANGED (always uses explicit
mode flags).

Wave note: This plan is in wave 7 because it shares files_modified with
Plan 08-09 (tests/test_tutorial.py + scripts/verify_phase8.sh). Plan 08-09
performs the 8→9 step-count sweep across both files; this plan then patches
the no-mode test + C7 check separately. By executing 08-10 AFTER 08-09 we
avoid merge conflicts on those two shared files.
