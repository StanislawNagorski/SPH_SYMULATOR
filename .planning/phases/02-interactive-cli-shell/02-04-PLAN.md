<!-- argparse introspection contract — Python stdlib argparse API the test relies on -->

`argparse.ArgumentParser` has `_actions` list (private but stable). Each action has:
- `.option_strings` → e.g. `['--zeta']`
- `.dest` → e.g. `'zeta'`
- `.type` → the type callable passed to `add_argument(type=...)`, e.g. `float`, `int`, `str` (NOT a string)
- `.default` → the default value passed to `add_argument(default=...)`

For mutex group members (from Plan 02), the actions still appear in `parser._actions` — mutex group membership is tracked separately in `parser._mutually_exclusive_groups` but does not hide actions from `_actions`.

Strategies registry (`sphsim.strategies.STRATEGIES.keys()`) → ['naive', 'threshold', 'phase_prob', 'incentive', 'adaptive'].

For each strategy, `sphsim.strategies.<name>.STRATEGY_META['params']` is a list of 4-tuples `(name: str, type: type, default: Any, description: str)` (Plan 01).

### How to expose argparse for introspection

`sphsim/cli/args.py` `parse_args()` builds the parser and returns `p.parse_args()` (calls sys.argv parsing). To introspect, we need the parser BEFORE parse is called. Two options the executor can choose:

Option A (refactor-free): Re-build the parser inline in the test by importing the same constants and inspecting attributes by re-running the setup logic. NOT preferred — duplicates the contract.

Option B (preferred, no production code change): Use `unittest.mock` to monkey-patch `argparse.ArgumentParser.parse_args` to capture the parser instance, then call `sphsim.cli.args.parse_args()` with `sys.argv=['x', '--strategy', 'naive']` so it doesn't crash on required mutex. Capture the parser via the monkey patch.

Option C (simplest, recommended): Call `parse_args()` with a controlled `sys.argv` providing `['x', '--strategy', 'naive']`, but BEFORE that, monkey-patch `argparse.ArgumentParser.parse_args` to return a no-op and stash `self` for introspection.

Pseudocode for Option C:
```python
import sys, unittest
from unittest.mock import patch

captured = {}
original = argparse.ArgumentParser.parse_args
def capture(self, *a, **kw):
    captured['parser'] = self
    return original(self, *a, **kw)

with patch.object(argparse.ArgumentParser, 'parse_args', capture):
    old_argv = sys.argv
    sys.argv = ['sph_sim.py', '--strategy', 'naive']
    try:
        from sphsim.cli.args import parse_args
        parse_args()
    finally:
        sys.argv = old_argv

parser = captured['parser']
actions_by_dest = {a.dest: a for a in parser._actions}
```

The executor is free to use any of A/B/C — Option C is suggested because it requires zero changes to production code and exercises the real parser setup.

### Test assertions (per strategy, per param tuple)

For each strategy name in `STRATEGIES.keys()`:
  Import its module, read `STRATEGY_META['params']`.
  For each `(pname, ptype, pdefault, pdesc)` tuple:
    Assert `pname in actions_by_dest`, else fail: `f"{strategy}: STRATEGY_META declares '{pname}' but argparse has no such add_argument"`.
    Action = `actions_by_dest[pname]`.
    Assert `action.type is ptype` (identity check on the type callable), else fail: `f"{strategy}/{pname}: STRATEGY_META type={ptype.__name__}, argparse type={action.type.__name__}"`.
    Assert `action.default == pdefault`, else fail: `f"{strategy}/{pname}: STRATEGY_META default={pdefault!r}, argparse default={action.default!r}"`.

Note: argparse `store_true` actions have `type=None`. Our strategy params are all typed, so this is not a concern for the 5 strategy params (zeta=float, max_phase=int, probs=str, s_target=int, expected_P=float).
