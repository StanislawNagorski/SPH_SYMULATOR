1. `do_help(self, arg)` — Override of cmd.Cmd's built-in. Print Polish list of 4 commands and their descriptions. Required content for CLI-02:

   - `exit` — Zakończ sesję (alternatywnie Ctrl+D).
   - `strategies` — Wyświetl listę wbudowanych strategii.
   - `strategy <nazwa>` — Wyświetl szczegóły strategii (parametry, baseline KPI).

   IMPORTANT: cmd.Cmd's built-in `do_help` walks `do_*` methods to print their docstrings. We OVERRIDE it for a single deterministic Polish output. Do NOT rely on cmd.Cmd help auto-generation.

2. `do_exit(self, arg) -> bool` — Print goodbye and return `True` (signals cmd.Cmd to stop the loop, D-20). Goodbye text MUST contain literal `Do widzenia.`.

3. `do_EOF(self, arg) -> bool` — Handle Ctrl+D. Print a newline first (so the goodbye doesn't appear on the same line as the partial prompt), then delegate to `do_exit` (single source of truth for goodbye text — Claude's Discretion). Return True.

     adaptive    — COMMIT zależnie od poziomu bufora SUS

   Implementation: iterate `STRATEGIES.keys()` (from `sphsim.strategies`); for each, dynamically import `sphsim.strategies.<name>` and pull `STRATEGY_META['description']`. Pad name to 12 characters with spaces, separator is em-dash ` — ` (U+2014 surrounded by spaces). Phase 3 (custom loader) will benefit because `STRATEGIES` is live mutable.

5. `do_strategy(self, arg)` — Per D-31/D-32:
   - If `arg.strip() == ''`: print `Użycie: strategy <nazwa>. Wpisz 'strategies' żeby zobaczyć listę.` (D-32 verbatim).

6. `default(self, line)` — Override cmd.Cmd's built-in. Per D-30:

   Where `{line}` is the literal user input (strip trailing newline if present).

### run_repl() implementation contract

```python
import os
import readline  # noqa: F401 — side effect: cmd.Cmd uses readline for line editing on POSIX
import atexit

HISTORY_FILE = os.path.expanduser('~/.sphsim_history')

def run_repl():
    try:
        readline.read_history_file(HISTORY_FILE)
    except FileNotFoundError:
        pass  # D-19: silent on first run

    atexit.register(lambda: readline.write_history_file(HISTORY_FILE))

    SPHShell().cmdloop()
```

Notes:
- `atexit` ensures history is saved even if user uses Ctrl+D (which exits cmdloop cleanly via do_EOF).
- No try/except around `cmdloop()` — Ctrl+C handling is cmd.Cmd default (catches KeyboardInterrupt internally per D-20). Actually per D-20: "Ctrl+C = anuluj bieżącą linię (cmd.Cmd default)". If your cmd.Cmd version raises KeyboardInterrupt at the top level, wrap with `while True: try: SPHShell().cmdloop(); break except KeyboardInterrupt: print()` — but only add this if testing reveals the default doesn't catch.
